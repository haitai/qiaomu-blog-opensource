# 乔木简阅 · K3 重设计说明

日期：2026-09-03 ｜ 设计者：Kimi K3 ｜ 样机：`index.html`

## 一、现方案（含上一轮 A 刊物红 / B 数字蓝 / C 墨绿签 / D 柠黄标）最致命的 3 个问题

1. **全部共享同一套"刊物思维"骨架**。四个方向都是"封面题图 + 章节编号行 + 正文"，遮住颜色后几乎无法区分：卡片化手机外壳、同样的引言行、同样的单行代码条。差异只停留在配色层，没有触达字体层级、H2 结构和空间节奏——这正是"不像编辑器默认值"却也不像任何真实产品的原因。
2. **把屏幕当成了纸**。米白底 + 墨绿 + 宋体标题是对"纸质文艺感"的安全模仿，但目标是中文 AI / 产品 / 工具长文，读者场景是微信里快速滑动的手机屏幕。纸感配色在手机 OLED 上发灰发闷，宋黑混排在 16px 正文尺寸下层级反而模糊，记忆点弱。
3. **装饰语法与内容无关**。左侧竖线、居中封面大字、引号伪元素、硬边投影这些都是"贴上去的风格"，不服务于"这段信息是什么层级"。真正的编辑设计应该让 H2/H3/引用/代码各自承担可识别的结构角色，读者遮住颜色也能靠结构导航。

## 二、四份互斥 brief

### A · 夜航（深色阅读舱）
- **世界**：夜间飞行的驾驶舱。墨蓝黑底（非纯黑），琥珀色只做航标——短下划线、H3、重点。
- **骨架**：H2 用 `display: table` 收缩包裹 + 3px 琥珀短下划线（线只与标题等宽）；H3 为琥珀色文字；引用是深色圆角舱块；代码块比底色更深一层。
- **气质**：安静、专注、适合晚间深度阅读；四个方向中唯一的深色方案。

### B · 蓝图注（工程简报）★ 推荐
- **世界**：产品团队的研读简报。冷白纸面 + 深青信号色，H2 底部一道通栏细发线收尾，H3 用深青信号色领起小节。
- **骨架**：H2 = 墨色标题 + `border-bottom: 1px solid` 通栏发线；H3 = 深青文字微字距；strong 是浅青信息高亮块；引用是上下双细线夹住的三明治；代码块是浅色纸面带行号。
- **气质**：理性、可信、导航效率最高，与 AI / 工具内容的"方法论"属性同构。

### C · 橙页（田野手册）
- **世界**：随身携带的田野调查手册。暖白纸面 + 工具橙，H2 是实心橙色圆角块（display:table 收缩包裹），像贴在页面上的一枚标签。
- **骨架**：实块标题 + 米色圆角小签 H3（`display: table` + 浅底 + 圆角）+ 圆角米色引用块 + 暖深棕代码终端；圆角语言贯穿全部组件。
- **气质**：四者中最有"人味"和行动感，适合实测、教程、清单类内容。

### D · 墨白（零彩度留白刊）
- **世界**：去掉一切彩色，只靠字重、字号、灰阶和线条建立层级，像 Monocle 的黑白页。
- **骨架**：H2 = 顶部 2px 粗线 + 全版面最大字号；H3 = 顶部 1px 细灰线呼应 H2；引用和代码块都是直角浅灰块；strong 用 2px 下划线而非颜色。
- **气质**：最克制也最冒险——零颜色意味着层级必须完全由排版承担，是"遮色测试"的基准答案。

**互斥性核对**（任意两方向 ≥4 条轴不同）：底色相（深/冷白/暖白/纯白）、H2 结构（短下划线 / 通栏发线 / 实色块 / 顶部粗线）、H3 结构（主色文字 / 信号色文字 / 浅色小签 / 顶部细线）、strong 处理（着色 / 浅底高亮 / 着色 / 下划线）、引用布局（深色舱块 / 双线三明治 / 圆角米块 / 直角灰块）、代码块明暗（更深 / 浅色纸面 / 暖深棕 / 浅灰）、圆角语言（10px / 8px / 12px / 0）、节奏（疏朗 / 紧凑网格 / 手册式 / 大留白）。

## 三、推荐方向：B · 蓝图注

理由：
- 目标内容是 AI / 产品 / 工具长文，读者第一需求是**快速定位章节**——通栏发线 H2 + 深青 H3 的标题系统是四个方案里导航效率最高的，且在 375px 宽度上不浪费任何横向空间。
- 浅色底在微信生态（白天通勤阅读）里可读性最稳；深青 `#0f7285` 与微信原生绿、链接蓝都拉开了距离，记忆点清楚但不刺眼。
- strong 的浅青高亮块替代"着色加粗"，在手机小屏上对重点的识别速度最快，且不依赖字重渲染差异。
- 对"文艺米白 + 墨绿"安全模板是最远的一次跳离，同时冒险度可控（7/10 而不是 9/10）。

A 适合作为未来的"夜间模式"延伸；C 是次选，若品牌想更暖更有手感可选；D 风险最高但辨识度也最高，适合作为态度声明。

## 四、每个方向如何映射为微信安全 CSS

四方向落地时都接入现有 `lib/wechat-themes.ts` 的 `buildEditorialCss`，只用实色、边框、圆角、内边距——无背景图、无远程字体、无滤镜；中文字重仅 400/500/600；无斜体；无 `#000`。

**H2/H3 落地硬约束**：四方向的 H2/H3 全部是纯文本原生标签，样式只作用在 `h2` / `h3` 选择器自身（字体、字号、字重、颜色、实色背景、全边框或上下边框、padding、margin、圆角、display）。不需要也不允许导出器注入任何 `<span>`、编号、计数器或改写标题文本；不用伪元素，不用左侧竖线。下表可直接映射为 `buildEditorialCss` 中普通 h2/h3 的样式对象。

| 主色 | 琥珀 `#f0a23c` | 深青 `#0f7285` | 工具橙 `#d35f0b` | 墨色 `#1b1b19` |
